# Hivestorm

A fast, one-thumb neon survivor shooter for phones and the mobile web.
Fly through glowing hordes, beat each stage's guardian, and turn every defeat into power — from stage 3 every guardian hides a weakness you have to discover.

**Play:** https://amirhosseinkazemiafshar.github.io/neon-swarm/

This repository holds the published web build only (one minified bundle, no third-party code, self-only Content-Security-Policy). All data stays on the player's device; nothing is sent to any server.
